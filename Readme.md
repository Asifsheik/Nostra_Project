# Nostra – Fashion Store Website

A responsive multi-page fashion storefront built with **HTML, Tailwind CSS and JavaScript**.

## Pages
- `index.html` – Home page with hero slider, brand list, highlights, new arrivals and newsletter form.
- `collections.html` – Product grid with live search and filters for occasion, colour and arrivals.
- `contactus.html` – Contact information and a responsive contact form.

## Tech stack
- HTML5
- Tailwind CSS 
- JavaScript
- Font Awesome icons
- Google Fonts (DM Sans and Playfair Display)
